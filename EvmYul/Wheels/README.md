# `EvmYul/Wheels/`: Basic types

Small types and helpers used everywhere: addresses, bytes, hex, RLP, JSON, chain parameters.

## Files

The library children of this folder (layout check L13 keeps this list complete):

- `Address.lean`: Account addresses.
- `Blob.lean`: Blobs.
- `Bytes.lean`: Byte arrays.
- `Chain.lean`: Chain parameters.
- `Debug.lean`: Debugging and profiling helpers.
- `Hex.lean`: Hexadecimal.
- `Json.lean`: JSON helpers.
- `Multiset.lean`: Sorted lists of multisets.
- `Option.lean`: `Option` helpers.
- `Primop.lean`: Primitive-operation signatures.
- `Rlp.lean`: Recursive-length prefix (RLP).
